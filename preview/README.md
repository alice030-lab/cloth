# 獨立 Web 操作預覽

`app.html` 是單一檔案、素材內嵌的瀏覽器互動預覽。下載後用桌面瀏覽器開啟即可；也可用靜態網站主機託管。此檔不是 Flutter 編譯產物，與 lib/ 的原生／Flutter 實作分開，不代表 P0 或原生去背已通過驗收。

可用：內建衣物與場景切換、圖層拖曳、圖層面板大小／旋轉／同層排序、鍵盤微移／移除、體型套用、復原／重做、圖片匯入與手動擦除／還原、自訂場景、瀏覽器草稿與作品保存／複製／刪除／重開、完成圖與前後對比 PNG 匯出、JSON 資料備份及清除資料。

未提供：AI 自動去背、原生相簿分享、Flutter 編譯、真實尺寸合身預測、多指手勢與完整 P0 驗收。體型調整作用於替身，衣物仍須手動微調。本機 file URL 儲存支援依瀏覽器而異，重要資料請下載備份。JSON 備份可保留資料供開發取用，目前尚無還原入口。

實際 Chromium 操作已通過：載入預覽、體型套用、儲存作品、重新載入、作品集重新編輯、完成結果、下載 PNG 並驗證檔頭。截圖為此 Web 預覽實際執行畫面，沒有冒稱 Flutter 截圖。

這個工作環境沒有公開託管／部署工具，所以未產生公開 App 網址。localhost 只用於內部驗證，不是使用者可開啟的預覽連結。
