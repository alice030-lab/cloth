# 視覺與操作更新 · 2026-11-03

本次修正回應原始 v3 與主頁參考圖的明顯落差：原版只有配色接近，人物、服裝與畫布比例未達產品品質。本次保留 Flutter 編輯器、資料庫、圖層及匯出服務，替換實際執行期素材與渲染；不是額外的 HTML 示意頁。

## 已實作

- 新增可局部調整胸、腰、臀、肩及腿長的寫實示範人物；錨點與渲染共用變形函式，保留原插畫模式。
- 12 件寫實服裝／鞋包與 1 組獨立前後髮；點選、拖曳、縮放、旋轉、圖層選取與儲存仍作用於獨立圖層。
- 五個本機寫實場景，場景選擇器與畫布共用同一張素材與取景資料。
- 4:5 畫布、較寬主視覺、場景縮圖膠囊、繁中襯線標題、保持比例的衣物縮圖。
- 開啟舊草稿時，吸附單品重新對準目前替身錨點，自由擺放單品保持位置；原始 before 快照不覆寫。
- 匯出前等待所需寫實素材解碼完成，前後畫面共用 4:5 比例，避免輸出暫時的向量替代畫面。

## 尚未完成的產品要求

寫實示範人物不代表「像使用者本人」已完成。尚無自拍替身與姿態偵測；三種性別表現皆已加入寫實外觀與插畫切換。參數變形未經人體量測校準，衣服是獨立 2D 圖層，不會自動隨身形改變布料輪廓，極端參數與髮際需要進一步美術修整。保養道具目前仍為插畫，動作回饋未達參考的細緻程度。

iOS 模擬器 App 與 Android debug APK 已由原生 CI 編譯通過；原生去背品質、權限及分享仍缺真機驗證，70 張真實圖片及 10 人研究未執行。這次不將全平台 P0 或正式視覺驗收標為完成。

執行與 A01–A20 詳見 README、ACCEPTANCE.md；實際 Flutter 截圖位於 screenshots/。

## 0.3 操作補齊

單點擦除／還原已接入實際修圖手勢，並用輸出 PNG 的 Alpha 像素驗證；原生處理可取消、25 秒逾時會保留原圖，取消後的延遲回應不會覆蓋編輯。自訂衣物與內建衣物皆使用透明度命中範圍，匯出前等待實際圖片解碼完成。

三種寫實外觀使用獨立示範人物，男性外觀校正肩線與褲／鞋寬度；圖層寬度可獨立調整並持久化。痘痘貼與精華增加臉部短暫回饋，狀態可復原並重算階段，動畫位於匯出範圍外。繁中標題宣告本機 fallback 字型，Flutter 的其他字形 fallback 也限制為同來源。
