## 實際驗證

- 47 項 Flutter 測試：26 模型／儲存、17 編輯器 widget、4 修圖介面。
- 7 項 Python 工具／Pages 測試；analyze 零問題；release Web 編譯成功。
- browser_care.mjs：首次單擊套用、44px 觸控範圍、不遮臉的初始狀態與單步復原。
- browser_audit.mjs：真實滑鼠拖曳、單步復原、可見調整／刪除操作；before.json／after.json 與選取畫面保存在同目錄 audit/。
- browser_update.mjs：修改實際 worker 檔案並由瀏覽器安裝；驗證提示、阻止刷新未完成面板、保存並恢復新草稿。測試結束會還原 worker 檔案，沒有把測試註解送進正式版本。
- 原有 browser_smoke.mjs 與 browser_acceptance.mjs 重跑，包含儲存、重開、PNG／對比卡、離線、作品改名／副本／刪除與清除。

更新提醒對載入 0.3.1 之後的分頁生效；既有 0.3 舊分頁仍需先手動重新開啟，新程式無法追溯替舊分頁加入提醒。更新不會自行刷新使用者的頁面。

## 仍有差距

目前仍是示範人物與獨立 2D 貼圖：服裝不會模擬布料、袖口與肢體遮擋，也不保證在身材極值貼合。鞋子透視已修，但仍需逐一校正各人物的落點。沒有自拍替身、本人像似度或真實合身預測。真機去背品質、權限／分享、70 張樣本與真人研究仍未通過驗收；不因自動化測試增加而把這些標為完成。
